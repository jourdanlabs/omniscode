# Roadmap

The following work is explicitly outside the V1 launch proposition:

1. Automatic completed-run receipts over canonical input/output/tool
   envelopes.
2. Independently reviewed checkpoint installation and host activation.
3. Cross-platform checkpoint authority.
4. New synthetic, signed public identity/policy fixtures with separately
   reviewed provenance.
5. Universal model/tool interception with explicit action authorization.
6. Evidence validators and source-bound claims.
7. Signed and notarized binaries, SBOM, SLSA provenance, and package managers.
8. A clean OMNIS config/storage namespace migration from jcode compatibility.
9. A public plugin/engine SDK.
10. A full sovereign OMNIS runtime gate.

Roadmap items are not present-tense claims and do not authorize provider spend,
credential use, installation, checkpoint activation, publication, or hosted
repository mutation.
