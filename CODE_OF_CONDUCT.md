# Code of conduct

We want technical disagreement to be direct, evidence-based, and safe for the
people involved.

Participants must:

- treat others with respect regardless of identity, experience, or viewpoint;
- critique claims and code without harassment, threats, sexualized attention,
  discrimination, doxxing, or personal attacks;
- protect private and security-sensitive information;
- disclose conflicts of interest and avoid grading their own release work;
- accept maintainers' good-faith decisions about project safety and scope.

Unacceptable behavior may be reported privately through the repository
maintainers using GitHub. Security vulnerabilities belong in the private
reporting flow described in `SECURITY.md`.

Maintainers may edit or remove contributions, limit participation, or ban a
participant when necessary to protect the project or community. Enforcement
decisions should state the relevant behavior and avoid unnecessary disclosure
of private information.

This policy applies in repository spaces and when a participant is publicly
representing the project.
