# Documentation map

The authoritative OMNIS KEY V1 documents are:

- `ARCHITECTURE.md`
- `THREAT_MODEL.md`
- `UPSTREAM.md`
- `UPSTREAM_DEBT.md`
- `OMNIS_KEY_RECEIPT_CORE.md`
- `OMNIS_KEY_CHECKPOINT_AUTHORITY.md`
- `OPEN_SOURCE_V1_RELEASE_SPEC.md`

Other top-level documents, plans, audits, proposals, and developer notes are
inherited jcode engineering material. They describe compatibility code,
historical experiments, or upstream plans; they are not OMNIS product claims
and may be stale.

The source candidate intentionally removes upstream marketing/demo media,
telemetry deployment documentation, historical release-note data, installers,
and release automation without rewriting Git history.
